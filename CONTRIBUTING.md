# Contributing to EcoSort AI

Thank you for your interest in contributing to **EcoSort AI**! We welcome community contributions to expand waste classification categories, enhance municipal recycling datasets, and improve civic sustainability.

---

## Code of Conduct
Please ensure a respectful, inclusive, and collaborative environment for all contributors.

---

## Development Workflow

1. **Fork the Repository:** Create your personal fork on GitHub.
2. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/awesome-improvement
   ```
3. **Set Up Local Environment:** Follow the steps in [docs/SETUP.md](docs/SETUP.md).
4. **Make Your Changes:** Keep changes atomic, well-documented, and adhering to PEP 8 standards.
5. **Run the Test Suite:**
   ```bash
   python -m pytest tests/ -v
   ```
   Ensure all tests pass before submitting.
6. **Submit a Pull Request:** Open a PR against `main` with a clear explanation of the changes made and any relevant screenshots.

---

## Project Areas Welcoming Contributions

- Additional waste classes (e.g., hazardous chemicals, textiles, medical waste).
- Localization and regional recycling regulations (EU green dot standards, North American resin codes).
- Offline PWA service worker caching improvements.
